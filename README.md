# پروژه EDITOR

این مخزن برای ساخت یک ویرایشگر آنلاین کد ایجاد شده است.

## قوانین پروژه

### قانون ۱: ساختار المان‌ها و بخش‌ها
- برای هر المان و هر بخش، یک پوشه مستقل ایجاد می‌شود.
- فایل‌های مربوط به هر المان یا بخش باید جدا از سایر بخش‌ها و در پوشه مخصوص خودش قرار بگیرند.
- هر پوشه شامل فایل‌های جداگانه موردنیاز همان بخش، از جمله `index.html`، `style.css` و `script.js` خواهد بود.
- فایل‌های اصلی در ریشه مخزن فقط برای ساختار و ظاهر کلی صفحه استفاده می‌شوند.
- منطق و کد اختصاصی هر المان یا بخش نباید در فایل‌های اصلی قرار بگیرد و باید در پوشه همان بخش نگهداری شود.
- بخش‌ها باید تا حد امکان مستقل و بدون تداخل با یکدیگر باشند.

### قانون ۲: زبان پروژه
- زبان تمام بخش‌های پروژه، به‌جز فایل README، انگلیسی است.
- نام فایل‌ها، پوشه‌ها، شناسه‌ها، کلاس‌ها، متغیرها و نوشته‌های رابط کاربری باید انگلیسی باشند.
- فایل `README.md` به زبان فارسی نوشته می‌شود.

### قانون ۳: محدوده فعلی توسعه
- در مرحله فعلی فقط ظاهر صفحه مادر طراحی می‌شود.
- سمت چپ صفحه برای نوشتن کد است.
- سمت راست صفحه برای نمایش زنده کد نوشته‌شده است.
- جداکننده بین دو بخش قابل تغییر اندازه است.
- در این مرحله منطق نوشتن کد و اجرای زنده پیاده‌سازی نمی‌شود.

### قانون ۴: رعایت دقیق درخواست
- فقط مواردی ساخته یا تغییر داده می‌شوند که کاربر صریحاً درخواست کرده است.
- هیچ قابلیت، بخش، عنوان یا جزئیات اضافی بدون درخواست کاربر اضافه نمی‌شود.
- نام‌گذاری المان‌ها بر اساس توضیح کاربر درباره کاربرد آن‌ها انجام می‌شود.

### قانون ۵: هدرها و فوتر
- صفحه شامل سه هدر است: هدر اصلی صفحه، هدر بخش کدنویسی و هدر بخش پیش‌نمایش.
- هدر اصلی صفحه در بالای صفحه ثابت می‌ماند.
- هدر بخش کدنویسی و هدر بخش پیش‌نمایش، نوارهای مجزای بالای پنل‌های مربوط به خود هستند.
- یک فوتر در پایین صفحه ثابت می‌ماند.
- محتوای اصلی در فضای بین هدر اصلی و فوتر قرار می‌گیرد.

### قانون ۶: نام‌گذاری هدرها و دکمه‌های هدر ادیتور
- نام هدرها در پروژه به‌ترتیب `Main Header`، `Editor Header` و `Live Header` است.
- در سمت چپ `Editor Header` دکمه‌های `Undo` و سپس `Clear` قرار می‌گیرند.
- دکمه `Redo` در سمت راست `Editor Header` قرار می‌گیرد.
- در این مرحله دکمه‌های `Undo`، `Clear` و `Redo` فقط ظاهر دارند و عملکرد آن‌ها پیاده‌سازی نمی‌شود.

### قانون ۷: دکمه‌های هدر اصلی
- در `Main Header` سه دکمه از سمت چپ و به‌ترتیب `Clear All`، `Download` و `Import` قرار می‌گیرند.
- در این مرحله این دکمه‌ها فقط ظاهر دارند و عملکرد آن‌ها پیاده‌سازی نمی‌شود.

### قانون ۸: تب‌های بخش کدنویسی
- در بخش کدنویسی سه تب با نام‌های HTML، CSS و JS وجود دارد.
- کاربر می‌تواند تب فعال را انتخاب کند.
- هر سه تب تمام عرض بخش کدنویسی را به سه قسمت مساوی تقسیم می‌کنند.
- در این مرحله تب‌ها فقط رابط ظاهری و وضعیت انتخاب را مدیریت می‌کنند و ویرایشگر واقعی کد پیاده‌سازی نمی‌شود.

## ساختار فعلی

```text
EDITOR/
├── editor/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── live/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── index.html
├── style.css
├── script.js
└── README.md
```

## مسئولیت فایل‌های ریشه
- `index.html`: ساختار کلی صفحه و بارگذاری بخش‌های مستقل.
- `style.css`: ظاهر و چیدمان کلی صفحه مادر.
- `script.js`: تغییر اندازه ستون‌های صفحه مادر.
