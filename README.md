# پروژه EDITOR

این مخزن برای ساخت یک ویرایشگر آنلاین کد با معماری مستقل و قابل توسعه ایجاد شده است.

## قوانین پروژه

### قانون ۱: ساختار قابلیت‌ها
- برای هر قابلیت، یک پوشه مستقل ایجاد می‌شود.
- هر پوشه قابلیت شامل سه فایل اصلی است: `index.html`، `style.css` و `script.js`.
- فایل‌های هر قابلیت باید تا حد امکان مستقل باشند.
- فایل‌های مادر در ریشه مخزن قرار می‌گیرند و قابلیت‌ها از طریق آن‌ها متصل و نمایش داده می‌شوند.

### قانون ۲: زبان پروژه
- زبان تمام بخش‌های پروژه، به‌جز فایل README، انگلیسی است.
- نام فایل‌ها، پوشه‌ها، شناسه‌ها، کلاس‌ها، متغیرها، توضیحات رابط کاربری و متن‌های داخل برنامه باید انگلیسی باشند.
- فایل `README.md` باید به زبان فارسی نوشته شود.

### قانون ۳: محدوده فعلی توسعه
- در مرحله فعلی فقط ظاهر صفحه مادر طراحی می‌شود.
- فعلاً قابلیت‌های اصلی و ابزارهای ویرایش کد پیاده‌سازی نمی‌شوند.
- صفحه مادر دارای دو پنل و یک جداکننده قابل تغییر اندازه است.
- محتوای نهایی هر پنل در مراحل بعدی مشخص خواهد شد.

## ساختار فعلی

```text
EDITOR/
├── index.html
├── style.css
├── script.js
└── README.md
```
