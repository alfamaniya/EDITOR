# پروژه EDITOR

این مخزن برای ساخت یک ویرایشگر آنلاین کد ایجاد شده است.

## قوانین پروژه

### قانون ۱: ساختار المان‌ها و بخش‌ها
- برای هر بخش یا المان، پوشه‌ای مستقل درون پوشه مادر `sections` ایجاد می‌شود.
- پوشه `sections` محل نگهداری تمام بخش‌های مستقل پروژه است تا با افزایش تعداد بخش‌ها، ریشه مخزن شلوغ نشود.
- هر بخش فایل‌های جداگانه موردنیاز خودش، از جمله `index.html`، `style.css` و `script.js` را در پوشه اختصاصی خود نگهداری می‌کند.
- فایل‌های اصلی در ریشه مخزن فقط برای ساختار و ظاهر کلی صفحه استفاده می‌شوند.
- منطق و کد اختصاصی هر بخش باید در پوشه همان بخش قرار بگیرد.
- بخش‌ها باید تا حد امکان مستقل و بدون تداخل با یکدیگر باشند.

### قانون ۲: زبان پروژه
- زبان تمام بخش‌های پروژه، به‌جز فایل README، انگلیسی است.
- نام فایل‌ها، پوشه‌ها، شناسه‌ها، کلاس‌ها، متغیرها و نوشته‌های رابط کاربری باید انگلیسی باشند.
- فایل `README.md` به زبان فارسی نوشته می‌شود.

### قانون ۳: محدوده توسعه
- صفحه اصلی شامل پنل کدنویسی در سمت چپ و پنل نمایش زنده در سمت راست است.
- جداکننده بین دو پنل قابل تغییر اندازه است.
- پنل کدنویسی سه تب HTML، CSS و JS دارد و هر تب محتوای مستقل خود را نگهداری می‌کند.
- کدهای سه تب با یکدیگر ترکیب می‌شوند و نتیجه در پنل Live نمایش داده می‌شود.
- تغییر کد در هر تب، پیش‌نمایش را به‌صورت زنده به‌روزرسانی می‌کند.
- اجرای کدهای پیش‌نمایش در یک iframe جداشده با sandbox انجام می‌شود.
- رنگ‌بندی دستورات با CodeMirror انجام می‌شود و برای هر زبان، حالت مناسب HTML، CSS یا JavaScript فعال است.
- انتخاب متن، مکان‌نما و محدوده دقیق انتخاب در مدل اصلی ویرایشگر نگهداری می‌شود؛ قابلیت‌های بعدی باید از همین محدوده استفاده کنند و نباید انتخاب را از روی متن رنگ‌بندی‌شده یا لایه نمایشی حدس بزنند.
- رابط برنامه‌نویسی داخلی برای خواندن متن انتخاب‌شده، دریافت ابتدا و انتهای محدوده انتخاب و جایگزینی همان محدوده فراهم است.
- دکمه Reset در هدر اصلی، محتوای هر سه ویرایشگر را به نمونه‌کدهای اولیه برمی‌گرداند و پیش‌نمایش را به‌روزرسانی می‌کند.

### قانون ۴: رعایت دقیق درخواست
- فقط مواردی ساخته یا تغییر داده می‌شوند که کاربر صریحاً درخواست کرده است.
- هیچ قابلیت، بخش، عنوان یا جزئیات اضافی بدون درخواست کاربر اضافه نمی‌شود.
- نام‌گذاری المان‌ها بر اساس توضیح کاربر درباره کاربرد آن‌ها انجام می‌شود.

### قانون ۵: هدرها و فوتر
- صفحه شامل سه هدر است: هدر اصلی صفحه، هدر بخش کدنویسی و هدر بخش پیش‌نمایش.
- هدر اصلی صفحه در بالای صفحه ثابت می‌ماند.
- هدر بخش کدنویسی و هدر بخش پیش‌نمایش، نوارهای مجزای بالای پنل‌های مربوط به خود هستند.
- یک فوتر در پایین صفحه ثابت می‌ماند.
- محتوای اصلی در فضای بین هدر اصلی و فوتر قرار می‌گیرد.

### قانون ۶: نام‌گذاری هدرها و دکمه‌های هدر ادیتور
- نام هدرها در پروژه به‌ترتیب `Main Header`، `Editor Header` و `Live Header` است.
- در سمت چپ `Editor Header` دکمه‌های `Undo` و سپس `Clear` قرار می‌گیرند.
- دکمه `Redo` در سمت راست `Editor Header` قرار می‌گیرد.
- دکمه‌های `Undo`، `Clear` و `Redo` فعلاً فقط ظاهر دارند و عملکرد آن‌ها پیاده‌سازی نشده است.

### قانون ۷: دکمه‌های هدر اصلی
- دکمه‌های هدر اصلی به‌ترتیب `Clear All`، `Download`، `Import` و `Reset` هستند.
- دکمه Reset محتوای HTML، CSS و JS را به نمونه‌کدهای اولیه بازمی‌گرداند و تغییرات کاربر را حذف می‌کند.

### قانون ۸: تب‌های بخش کدنویسی
- در بخش کدنویسی سه تب با نام‌های HTML، CSS و JS وجود دارد.
- کاربر می‌تواند تب فعال را انتخاب کند.
- هر سه تب تمام عرض بخش کدنویسی را به سه قسمت مساوی تقسیم می‌کنند.
- هر تب ویرایشگر مستقل دارد و محتوای آن هنگام جابه‌جایی بین تب‌ها حفظ می‌شود.

### قانون ۹: ذخیره خودکار کدها در مرورگر
- هر تغییری که در ویرایشگرهای HTML، CSS و JS انجام می‌شود، به‌صورت خودکار در حافظه محلی مرورگر (`localStorage`) ذخیره می‌شود.
- هنگام بازکردن یا بارگذاری مجدد صفحه، آخرین کدهای ذخیره‌شده هر سه ویرایشگر بازیابی می‌شوند.
- با اجرای Reset، داده‌های ذخیره‌شده پاک می‌شوند و نمونه‌کدهای اولیه دوباره نمایش داده می‌شوند.
- ذخیره‌سازی به همان مرورگر و همان دستگاه محدود است و با پاک‌کردن داده‌های سایت یا استفاده از مرورگر/دستگاه دیگر در دسترس نخواهد بود.

## ساختار فعلی

```text
EDITOR/
├── sections/
│   ├── editor/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   ├── live/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── script.js
│   └── reset/
│       ├── index.html
│       ├── style.css
│       └── script.js
├── index.html
├── style.css
├── script.js
└── README.md
```

## مسئولیت فایل‌های ریشه
- `index.html`: ساختار کلی صفحه و بارگذاری بخش‌های مستقل از پوشه `sections`.
- `style.css`: ظاهر و چیدمان کلی صفحه مادر.
- `script.js`: تغییر اندازه ستون‌های صفحه مادر و هماهنگی پیام‌ها بین Editor، Live Preview و Reset.
